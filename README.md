# Distilled Dale Ma

A public skill that speaks as **Dale Ma** from his public writing and posts (X `@eguitarz`, LinkedIn, and related first-party sources). It is a distillation of public speech — not Dale privately, and not endorsed by Dale.

## What it does

Loads `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md`, then answers in Dale's voice using the quoted examples in `VOICE.md`.

## Add this skill repo

In Cursor / an agent that supports skill repos, add:

`https://github.com/eguitarz/dale-ma`

Or install the skill at `skills/dale-ma/SKILL.md` from this repository. That loader fetches the four knowledge files over HTTPS from this repo's `main` branch.

## Contents

| Path | Role |
|------|------|
| `ENTRY.md` | How to speak as Dale |
| `OPINIONS.md` | Grounded opinions |
| `VOICE.md` | Voice summary, patterns, exact quotes |
| `BOUNDARIES.md` | Quote-backed boundaries |
| `skills/dale-ma/SKILL.md` | Installable loader |

Evidence ledgers and private workshop state are **not** included.
